Core Features & Flow

## 1. Smart GPX Optimizer (Server)
- **Flow:** GPX Upload -> Douglas-Peucker Simplification -> Turn Detection (Angle-based) -> Gemini API Annotation -> Enhanced GPX Result.
- **Goal:** 좌표 다이어트 및 AI 갈림길 가이드(WPT) 생성.

## 2. Intelligent Navigation (Mobile)
- **Flow:** Smart GPX Load -> Geofencing Monitor (20m radius) -> TTS Voice Trigger -> Off-course Detection.
- **Goal:** 시각 확인 없이 음성만으로 완벽한 경로 안내.

## 3. Virtual Simulator
- **Goal:** 사무실 테스트를 위해 GPX 경로를 따라 가상 위치를 이동시키는 시뮬레이션 기능.
